# قصاصة | Qusasah — الموقع الرسمي

موقع صفحة واحدة لوكالة قصاصة الإبداعية.

## النشر على GitHub Pages
1. ارفعي محتويات هذا المجلد إلى المستودع (index.html في الجذر).
2. Settings → Pages → Source: Deploy from a branch → main → / (root).
3. الموقع يظهر خلال دقائق على: https://USERNAME.github.io/REPO-NAME/

## إضافة صور الأعمال
ضعي الصور في مجلد `images/` ثم في index.html استبدلي:
`<div class="ph">صورة المشروع</div>`
بـ:
`<img src="images/اسم-الصورة.jpg" alt="وصف العمل">`
